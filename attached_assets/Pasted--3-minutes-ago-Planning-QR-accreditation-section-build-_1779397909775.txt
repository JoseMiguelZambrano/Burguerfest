Visión general del sistema
El sistema tiene 3 piezas que trabajan juntas:

/acreditar/:code — Página del patrocinador. Muestra su QR para presentar en entrada.
/scanner — App del personal de entrada. Escanea QR con cámara, valida el código.
Admin → tab "Patrocinadores" — Panel interno. Genera el QR de cada patrocinador y lo envía por WhatsApp.

pnpm add html5-qrcode qrcode.react

html5-qrcode — acceso a cámara + lectura de QR en el navegador

Pieza 1 — Página de acreditación del patrocinador
Ruta: /acreditar/:code
Archivo: src/pages/AcreditacionPage.tsx

Qué hace: El patrocinador recibe un link por WhatsApp. Al abrirlo ve esta página con su nombre, nivel, y un QR grande para mostrar al personal de entrada.

Diseño: Fondo oscuro #0f1117, tarjeta blanca centrada con el QR dentro, logo del evento arriba, instrucciones abajo.

import { useParams } from "wouter";
import { QRCodeSVG } from "qrcode.react";
import { CheckCircle, XCircle } from "lucide-react";
import { findSponsorByCode } from "@/data/sponsors-accreditation";
// Colores por nivel de patrocinio
const tierColors: Record<string, string> = {
  Gold: "bg-yellow-400 text-yellow-900",
  Silver: "bg-slate-300 text-slate-800",
  Bronze: "bg-amber-700 text-amber-100",
};
export default function AcreditacionPage() {
  const { code } = useParams<{ code: string }>();
  const sponsor = code ? findSponsorByCode(code) : null;
  // Estado de error: código inválido o no encontrado
  if (!sponsor) {
    return (
      <div className="min-h-screen bg-[#0f1117] flex flex-col items-center justify-center px-6 text-center gap-6">
        <XCircle className="w-20 h-20 text-red-400" strokeWidth={1.5} />
        <div>
          <h1 className="text-2xl font-bold text-white">Código no válido</h1>
          <p className="text-white/40 text-sm mt-2">
            Este enlace de acreditación no existe o ha expirado.
          </p>
        </div>
      </div>
    );
  }
  return (
    <div className="min-h-screen bg-[#0f1117] flex flex-col items-center justify-center px-6 py-12">
      <div className="w-full max-w-sm flex flex-col items-center gap-8">
        {/* Cabecera con logo */}
        <div className="flex flex-col items-center gap-3 text-center">
          <img
            src="/images/logo-dark.jpeg"
            alt="Burger Fest"
            className="w-16 h-16 rounded-2xl object-cover"
          />
          <h1 className="text-2xl font-bold text-white tracking-tight">Burger Fest 2026</h1>
          <p className="text-white/40 text-sm">Credencial de patrocinador</p>
        </div>
        {/* Tarjeta blanca con QR */}
        <div className="w-full bg-white rounded-3xl p-8 flex flex-col items-center gap-6 shadow-2xl">
          {/* Datos del patrocinador */}

              Patrocinador {sponsor.tier}

Pieza 2 — Escáner QR para personal de entrada
Ruta: /scanner
Archivo: src/pages/ScannerPage.tsx

Qué hace: Pantalla de PIN → pantalla de escáner con cámara → pantalla de resultado (verde/rojo). Vuelve automáticamente al escáner tras 5 segundos.

Diseño: Todo fondo oscuro #0f1117. Sin navbar ni footer — es una app de uso interno a pantalla completa. La pantalla de resultado es completamente verde (bg-green-950) o roja (bg-red-950) según el resultado.
